TOS actor sheets

A redesign of the 2e character sheet in the style of the TOS task and chat cards: gunmetal housing panels, curved CRT screens with phosphor type, and raised backlit keys. The tracks are rows of lit keys, the attribute and discipline selectors are indicator lamps, and the tabs are console keys. Below the character sheet's Traits and Character tabs are the NPC, supporting character, starship (Ship and Crew tabs) and small craft sheets, all with sample data.

    How this would be built

    This would be a CSS overlay, not a new template. The renderCharacterSheet hook would add a sta2e-tos-sheet class to the sheet root under the TOS theme, and every rule would hang off that class, as the mockup's do. Every data-action, input name and system script keeps working, because nothing in the system's markup moves. That includes the track renderer, which rebuilds div.box.stress.selected on each render.

    The parts that can't be done in CSS alone are a few small hook additions: the panel header strips and lamps, the "Personnel File" plate under the portrait, the wrapper that draws the CRT bezel, and lamp toggles for Values in place of the system's slider icons. The system's own colour palette variables (--sta-*, which the Crew tab also reads) would be set to the TOS colours, so anything the system adds later picks up the theme.

    NPC and supporting character sheets. They use the same template skeleton, so one overlay covers all three. Three extra pieces are styled here: the type selector (.npc-block radios), the NPC's Personal Threat track and the supporting character's milestone grid (.supporting-char-grid). The NPC sheet's Personal Threat track reuses the system's #bar-stress-renderer, so its keys carry the class box stress, exactly like a character's Stress track. CSS can't tell them apart, so the hook also stamps the actor type on the root (data-sheet="npc"), and that's what turns the Threat keys orange. Neither sheet has Acclaim or the reputation toggle, and the NPC sheet has no Development tab. Their panels are simply shorter, and nothing else needs its own rules.

    Starship and small craft sheets. These two templates are different from the character sheets but identical to each other: both use .starship-sheet, and the small craft one leaves out Crew Support, the Crew Modifier and the Launch Bay. They have no tabs of their own, so the toolkit's Ship/Crew strip and the NPC Ship block are styled as part of the same console. A system's breach count turns red when it's above zero. That needs no script: the template writes the count as the input's value attribute, so .breaches:not([value="0"]) works on every render. The Crew Support and Shields tracks are drawn by the same renderer as the character tracks, as box crew and box shields, and get gold and blue keys.

    The toolkit's Allied NPC block. On ground NPC sheets the toolkit also adds an Allied NPC block, with the same lamp checkbox as the NPC Ship block. It isn't shown here, but it takes the same rules.
