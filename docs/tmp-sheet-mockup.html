TMP actor sheets

The 2e actor sheets in the style of the TMP Console Monitor task card: grey duty panels with a coloured header plate, black monitors for the statistics (the portrait included), dark recessed windows with amber type for fields and lists, and backlit lens keys. Tracks are rows of lenses, the attribute, discipline, system and department selectors are small lenses that light yellow, and tabs are lens keys set in a key bed. The character sheet's Traits and Character tabs come first, then the NPC, supporting character, starship (Ship and Crew tabs) and small craft sheets, all with sample data. Hover a list row to see its edit and delete keys.

    How this would be built

    The same way as the TOS sheets: a CSS overlay, not a new template. tos-sheet-theme.js already stamps the five 2e sheets from their render hooks; under tmp-console it would add .sta2e-tmp-sheet instead of .sta2e-tos-sheet, with the same data-sheet="<kind>" stamp, and a new styles/tmp-sheet.css would hang every rule off that class. Nothing in the system's markup moves, so every data-action, input name and the track renderer keep working. The panel header plates, the "Personnel File" caption and the indicator lenses are pseudo-elements, as on TOS.

    Colours, by surface. Black monitors carry the statistics in the later films' palette: cyan captions and borders, green numbers, yellow for whatever is selected, magenta for breaches and injuries. Text the player types (names, fields, list entries) sits in dark recessed windows in amber, the first film's readout colour. Everything else is the light grey panel with dark engraved labels. That split also keeps the sheet readable: nothing light-coloured sits on the grey.

    Tracks use the system's div.box.<kind>.selected markup: Reputation and Crew Support light amber, Determination and Shields cyan, Stress magenta. The NPC's Personal Threat reuses box stress, so data-sheet="npc" is what turns it orange (and the NPC's header plates magenta). Breaches turn magenta through .breaches:not([value="0"]), which works because the template writes the count as the value attribute.

    Fonts. The overlay would reuse the fonts the TMP task card already bundles (fonts/tmp/, declared in task-card-tmp.css), so the sheets need no new files.

    Toolkit additions take the same rules: the Crew tab, the NPC Ship block, the Allied NPC block on ground NPC sheets, and the Wear / Repair / grenade-count controls on belongings rows.
