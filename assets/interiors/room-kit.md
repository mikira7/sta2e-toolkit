# Pre-rendered Starfleet room kit

Generated using the built-in ImageGen tool for this project. These are opaque floor-and-furniture images. Native layout walls and doors are added by the module. All room images use uniform scaling and remain within furnishing frames; unsupported or very narrow rooms use individual furniture assets.
